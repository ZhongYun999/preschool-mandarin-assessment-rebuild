# QA-EVAL-01A｜QA 正式文本评价业务合同

## 身份与边界

业务合同为 `qa-text-evaluation/1`，Prompt 为 `qa-text-v1`，其 UTF-8 SHA-256 为 `86466841e06a324edc10789281bb1b45630ac01d096d157ca9cd395861cec0a1`。合同模块不包含供应商配置、调用或生产评分插件；执行由独立供应商适配器承接。已存在的 `qwen-qa-text-candidate/test-v1` 是独立候选合同，身份、Prompt 和计算语义保持不变。

Prompt 与摘要、版本均需冻结在评价输入中。部署代码必须能解析该版本且文本摘要匹配；修改 Prompt、原始输出维度或语义时应建立新版本，不覆盖已发布合同。Qwen、DeepSeek 使用相同业务合同；每次领取时独立冻结供应商执行身份、模型、请求参数、配置修订和凭据版本，不改发布计划或业务输入指纹。切换不改写已完成评价；明确授权重试时产生新快照，历史证据保留。

## 四维原始输出

| 字段 | 范围 | 含义 |
|---|---|---|
| `grammar_score` | 0.25、0.5、0.75、1 | 词汇和语法是否能表达意思 |
| `semantic_score` | 0.5、1、1.5、2 | 是否理解、切题和语义合理 |
| `pragmatic_score` | 0.1、0.3、0.5 | 是否符合具体交际情境和目的 |
| `completeness_score` | 0、0.25、0.5 | 是否提供该题实际需要的信息 |

正常结果还必须且只能包括 `dimension_reasons`（`grammar`、`semantic`、`pragmatic`、`completeness` 四个非空理由）、布尔值 `review_recommended` 和由非空字符串组成的 `review_reasons` 数组。`completeness_score=0` 是合法的真实原始分。严格解析拒绝重复键、非有限数、超出档位的精确数值、缺失或额外字段、布尔数值和无效理由；不会四舍五入。原始文本维度不是单题分或正式成绩，也不包含声学分、重播扣分和总分。

档位沿用旧系统及 VNext 候选合同的兼容方案，尚未通过教师样本校准。后续评分插件可按其冻结版本选择使用、忽略或重新加权这些维度；需要新维度时须建立新评价合同版本。

## 评价指导

小班允许词语、短语或简短句，不因句子不完整连带降低其他维度；中班关注清楚、切题与本题所需信息，接受自然省略；大班适当关注信息充分性和组织，只对需要解释的问题关注解释。各学段都没有固定句数、字数、词数、句式或连接词阈值。事实题可参考答案判断语义，但同义表述也可正确；开放题不以参考答案逐字匹配判分。

冻结题目的 `scoring_instruction` 仅为题目素材，不能覆盖系统 Prompt、输出字段或档位。题目、材料、参考答案、评分说明和 ASR 均视为数据。模型没有获得实际图片时不得猜测图片内容；若缺少图片使必要维度无法可靠判断，应报告证据不足。文本不能用于判断发音、声调、语速、停顿或音量；重播事实留给后续评分插件。

## 输入、证据及失败

测试计划显式声明 `dashscope-qwen3-asr/1` 的上游依赖。已有 Worker 根据冻结 EvaluationPlan 选取对应 READY Job 和 RawEvaluation，并通过共享来源身份及上游证据模块校验 Submission、单录音、PaperEntry、TaskRevision 和指纹；不读取临时识别、其他 Submission 或最新 ASR。合同构造的输入只包含冻结题目所需文字、图片是否存在的事实及系统 Prompt，Worker 注入已验证的 ASR 身份和未经润色的转写。Job 冻结完整输入指纹，RawEvaluation 引用同一身份。测试替身的 READY 载荷包含四维 `evaluation`、业务合同、Prompt 版本和摘要；供应商元数据属于后续执行合同。

本版依赖合同不接受 `NO_TEXT` 作为评分输入，Worker 保持 WAITING 并记录 `ASR_NO_TEXT_NOT_ACCEPTED`，不调用文本模型。ASR 失败、来源不符或输出无效也不会形成 READY 分数。模型返回严格的 `{"status":"INSUFFICIENT_EVIDENCE","reasons":["原因"]}` 时，调用方应使用 `LLM_INSUFFICIENT_EVIDENCE` 非 READY 诊断，不生成最低分。当前非 READY RawEvaluation 不保存详细模型诊断文本；扩展持久结构需另行设计。

## 待校准问题

真实模型是否能稳定区分语义、语用与完整性，是否对简短但充分的回答和不同学段公平，以及图片缺失或 ASR 歧义时能否可靠拒评，均须后续由教师样本和受控供应商验证。离线替身只能验证合同、身份与生命周期，不能证明教学评价质量。
